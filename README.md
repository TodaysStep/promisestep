# PromiseStep

Refactoring for Kindness.

PromiseStep is an open-source SDK for designing and building accessible software that preserves human judgment, records, boundaries, creative authorship and continuity.

The first release includes local JavaScript/TypeScript and Python protections, a Java public-read client, source bindings for Apple platforms, and a bounded public read API. Owner services, private custody, automated web discovery and formal constitutional admission are separate integration requirements; a contract listing is not a deployed owner service.

Source and verified release evidence are being assembled in this repository. The live developer platform is https://promisestep.com/.

Do not put private records, credentials or confidential research in this repository. No GitHub-hosted build workflows are configured.
